# Official Docs Wiki

이 위키는 해커톤 발표 자료를 보관하는 곳이 아니라, **공식 규칙과 기술 문서를 제품 결정으로 바꾸는 기준점**이다. 로컬 전사 3개와 PDF OCR 3개에서 중요한 주장을 추출해 1차 출처와 대조하고, 그 결과를 현재 제품인 [Mandate Pool](../../product/mandate-pool/README.md)의 구현·검증·제출 기준으로 연결한다.

- 비교 데이터 기준일: 2026-07-23
- 고영향 공식 사실 재확인일: 2026-08-03
- 가변성이 가장 큰 출처: [공식 행사 페이지](https://www.gcp-solana-ai-agentic-hacks-kr.xyz/)

## 사용하는 방법

1. [인덱스](index.md)에서 현재 결정과 남은 불확실성을 확인한다.
2. 해당 모듈에서 공식 사실을 구현 수용 기준으로 바꾼다.
3. 비교 페이지는 전사·OCR 문구를 인용해야 할 때만 연다.
4. 제품 설명에는 구현한 프로토콜만 적고, fixture·sandbox·Devnet 증거의 범위를 정확히 표시한다.
5. 제출 직전 행사 페이지, 제출 폼, 사용 중인 프로토콜 버전을 다시 확인한다.

## 판정 언어

| 판정 | 의미 | 독자가 취할 행동 |
|---|---|---|
| 일치 | 현재 공식 문서가 같은 핵심 의미를 명시한다. | 날짜·버전과 함께 사용할 수 있다. |
| 부분 일치 | 방향은 맞지만 조건·범위·예외가 빠졌다. | 누락 조건을 보완한 뒤 사용한다. |
| 상충 | 현재 공식 문서와 직접 다르다. | 공식 문서 표현으로 교체한다. |
| 버전 드리프트 | 당시에는 맞았을 수 있으나 현재 명칭·버전·절차가 다르다. | 현재 버전을 고정하고 마이그레이션한다. |
| 공식 근거 없음 | 조사한 1차 출처에서 확인하지 못했다. | 거짓으로 단정하지 말고 서면 확인 전까지 의존하지 않는다. |
| OCR 오류 | 기계 추출 결과가 공식 명령·용어를 재현하지 못했다. | 원문 또는 공식 코드 블록을 사용한다. |

## 이 프로젝트에 적용하는 핵심 경계

- 행사는 **Solana 기반 Agentic Commerce 단일 트랙**이며 A~D는 아이디어 범주다. 네 개의 독립 트랙으로 제출 전략을 나누지 않는다.
- 평가용 실행은 localnet·testnet·Devnet에서 가능하다. Mainnet과 실제 자산은 필요하지 않다.
- fixture와 pay.sh sandbox는 개발 증거다. 온체인 증거라고 표현하지 않는다.
- Mandate Pool은 세 구매자의 한도와 세 전송을 하나의 Solana 거래로 묶는 custom atomic settlement다. 구현하지 않은 x402·AP2 호환성을 주장하지 않는다.
- 에이전트 제안, 결정론적 정책 판정, 사람 승인, 지갑 서명, finalized 검증을 한 감사 흐름으로 보여준다.

## 증거와 보안 원칙

- 주최자, Google, Solana, pay.sh, Coinbase/x402, MPP, 각 프로토콜 관리 주체의 공식 문서만 사실 판정 근거로 사용한다.
- 전사와 OCR은 검색 단서다. 화자 신원, 깨진 명령, 시점 의존 수치를 원 사실로 승격하지 않는다.
- 공식 문서가 말하지 않는 사항은 추정하지 않는다.
- 저장소에는 Mainnet 자산, 개인키, 자격 증명, `.env`, secret payload를 기록하지 않는다. 공개 주소와 Devnet transaction signature만 증거로 남긴다.

- [manifest](manifest.json): 입력 artifact와 공식 출처 목록
- [claim ledger](claim-ledger.json): 37개 비교 판정의 구조화 데이터

이 위키는 문서 감사를 제공한다. 실제 Cloud Run 배포, Gemini 호출, 지갑 승인, Solana 거래 성공, 심사 통과는 각각 별도의 런타임 증거가 필요하다.
