# Official Docs Difference Wiki

이 폴더는 로컬 전사·OCR 산출물 6개를 2026-07-23 현재의 1차 공식 문서와 대조한 별도 리서치 위키다. 원본 문서나 `.harness/` 산출물을 수정하지 않는다.

## 판정 규칙

| 판정 | 의미 |
|---|---|
| 일치 | 현재 공식 문서가 같은 의미를 명시한다. |
| 부분 일치 | 핵심은 맞지만 조건·범위·예외가 빠졌다. |
| 상충 | 현재 공식 문서와 직접 다르다. |
| 버전 드리프트 | 당시 설명일 수 있으나 현재 명칭·버전·절차가 달라졌다. |
| 공식 근거 없음 | 이번 조사 범위의 1차 공식 문서에서 확인하지 못했다. 사실이 거짓이라는 뜻은 아니다. |

## 조사 원칙

- 주최자 행사 페이지와 Luma 일정, Google·Solana·pay.sh·x402·MPP·각 프로토콜의 공식 문서만 사실 판정의 근거로 사용했다.
- 검색 결과, 블로그 재게시, 커뮤니티 글은 공식 계약으로 승격하지 않았다.
- 전사와 OCR은 검색용 단서로만 사용했다. 음성 인식 오류와 슬라이드 레이아웃 손실은 원 주장으로 확정하지 않았다.
- 행사 페이지는 변경될 수 있다. 제출 직전에는 [현재 행사 페이지](https://www.gcp-solana-ai-agentic-hacks-kr.xyz/)를 다시 확인해야 한다.
- 공식 문서가 침묵하는 내용은 추정하지 않고 `공식 근거 없음`으로 남겼다.

## 검증 범위

이 결과는 공식 문서의 현재 표현과 로컬 문서의 차이를 찾는 문서 감사다. 법률 자문, 모든 생태계 수치의 독립 검증, 실제 지갑 결제 성공, 제출 승인 여부를 증명하지 않는다.
