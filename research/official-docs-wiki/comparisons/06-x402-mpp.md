## Mandate Pool 결정

현재 제품의 architecture에는 ADK/Gemini, project-specific policy proof, custom Solana settlement만 구현돼 있다. 이 deck의 protocol map은 후속 확장 방향을 설명하는 연구 자료이지 제출용 integration 목록이 아니다.

- buyer별 cryptographic authority 표준화가 필요하면 AP2 검토
- 외부 merchant checkout이 필요하면 UCP/ACP 검토
- paid HTTP resource가 필요하면 x402 v2 또는 MPP 검토
- independent remote agent collaboration이 필요하면 A2A 검토
- agent-tool 표준 연결이 필요하면 MCP 검토

## 실행 항목

1. 아키텍처 그림에서 미구현 protocol logo를 제거한다.
2. x402 code를 추가할 경우 v2 fixture와 CAIP-2 network test를 먼저 만든다.
3. MPP session을 주장할 경우 cap·expiry·close·failure 상태와 실제 비용 benchmark를 제공한다.
4. market metric은 source dataset·query·기준일이 없으면 삭제한다.

프로토콜의 전략적 가치는 이름의 수가 아니라, 기존 custom interface 하나를 더 명확하고 상호운용 가능한 계약으로 교체하는 데 있다.
