# 행사 계약과 일정

상태: 2026-07-23 현재 확인

## 공식 출처

- [Google Cloud × Solana AI Agentic Hackathon 공식 행사 페이지](https://www.gcp-solana-ai-agentic-hacks-kr.xyz/)
- [Kickoff & Tech Session 공식 Luma 페이지](https://luma.com/gcp-solana-tech-session?locale=ko)

## 정규화 추출

- 빌드 기간: 2026-07-17 ~ 2026-08-03.
- 킥오프: 2026-07-21 19:00~21:00.
- 제출 마감: 2026-08-03 23:59 KST.
- 파이널리스트 발표: 2026-08-07.
- 멘토링: 2026-08-10 ~ 2026-08-20.
- Demo Day: 2026-08-21, Google for Startups Campus.
- 팀은 최대 4명이며 개인 참가도 가능하다.
- 제품은 한국어 또는 영어, 발표는 한국어로 안내된다.
- 네 트랙은 Agent-Initiated Commerce, Autonomous On-chain Settlement, Multi-Agent Commerce, Verifiable Distribution at Scale이다.
- 현재 공개된 제출물 상위 범주는 제품 소개, GitHub 저장소, 데모 영상이다. 라이브 배포 엔드포인트는 권장된다.
- 평가는 혁신·UX, Gemini/Google Cloud AI 활용, Solana·Google Cloud·에이전트/결제 프로토콜 통합의 기술 완성도, 실제 작동 증거를 본다.
- 현재 실제 작동 문구는 localnet/testnet/devnet에서 에이전트가 트랜잭션을 유발하고 결제를 완료하며 로그 또는 이력으로 확인 가능해야 한다는 취지다.
- 총 상금은 USD 5,000이며 1·2·3위는 각각 3,000·1,500·500이다. FAQ는 Solana Foundation Grants Program의 직접 지급 및 Solana 글로벌 해커톤 참여·제출 시 절반 지급 조건을 안내한다.
- 공식 Luma의 세션 순서는 행사 소개, Four Pillars, Google Cloud, Solana, Q&A다.

## 공식 페이지에서 확인되지 않은 세부 사항

현재 페이지에는 `3분 데모`, 특정 PPT 필수 목차, 특정 아키텍처 다이어그램, 개인 Gmail 필수, 기존 프로젝트 허용 범위가 명시되어 있지 않다. 이런 내용은 별도 공식 약관 또는 제출 폼이 제시되기 전까지 확정 규칙으로 쓰지 않는다.

## 사용 지침

구현 수용 기준은 `에이전트가 결제를 야기함 + 트랜잭션/결제 완료 + 감사 가능한 로그/이력`으로 잡되, Mainnet을 현재 공식 필수 조건으로 추가하지 않는다.
