## 정규화 추출

- x402는 HTTP 402 응답으로 결제 요구를 전달하고, 구매자가 결제 서명을 보내면 facilitator 또는 판매자가 검증·정산한 뒤 리소스를 반환하는 흐름이다.
- 현재 문서의 권장 버전은 v2다. v1의 `X-PAYMENT` 헤더 중심 예시는 v2의 `PAYMENT-REQUIRED`·`PAYMENT-SIGNATURE` 흐름 및 CAIP-2 네트워크 식별로 갱신해야 한다.
- 프로토콜 목표는 계정·세션·복잡한 인증 의존을 줄이는 것이지만 구현에 지갑과 서명은 필요하다.
- facilitator 선택에 따라 인증 요구가 다르다. CDP facilitator의 권장 경로는 CDP 자격 증명을 사용하고, 공개 테스트 facilitator 경로는 조건이 다르다.
- 현재 CDP buyer 문서는 Solana와 Solana Devnet 지원 경로를 안내한다.

## 오해 방지

`x402는 API key가 전혀 없다`는 보편 명제는 공식 구현 선택지와 맞지 않는다. 프로토콜의 계정 없는 결제 목표와 facilitator 운영 인증을 별도 층으로 표현한다.
